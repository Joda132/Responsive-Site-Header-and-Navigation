5. JavaScript code defense

Explain initialization, state synchronization, activation, and Escape/focus behavior in your own words. Refer to the exact variable, attribute, dataset value, function, and event used.

Initialization: This adds the js class to the <<html>> so that the CSS is able to hide the list only when Javascript is running. It sets button.hidden=false and calls setOpen(false)

State synchronization: The setOpen(isOpen) will set teh aria-expanded ON button and toggles the is-open on list together.

Activation: the click event will call the setOpen with the opposite state. And a native button fires click for enter ane space.

On the keydown if the event.key is "escape" and the menu is open it will cal setOpen(false) and button.focus().
