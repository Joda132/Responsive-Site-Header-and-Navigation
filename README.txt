Site description:
The ASU library is a three page site that is meant to allow students to find books, attend events, 
get tech support, and check the library hours and location. I use the same responsive header and nav for every page.

Files:
- index.html: Home page
- visit.html: hours and location page
- support.html: tech support page
- styles.css: shared header, breakpoint styles, state, and navigation
- navigation.js: small enhancement for the narrow Menu button
- navigation-plan.html: All of the requirements completed
- 200zoom.png: Shows 200 percent
- wide_focus: Shows proper focus
